# Portable Altimeter

A compact Arduino-based altimeter designed for portable use. This project reads air pressure data from a sensor, calculates altitude, and displays the result on a small screen.

## Hardware

- Arduino Uno R4 wifi board 
- Barometric pressure sensor BMP280
- OLED display 128x64
- Breadboard 
- External power supply - 5V
- Push button
- Jumper wires


## Usage

1. Switch on the power supply.
2. Wait for the sensor and display to initialize.
3. The screen will prompt: "Set the base pressure and press the button."
4. Press the button once to set the base pressure.
5. Press the button again anytime to recalculate altitude from the stored base pressure.
