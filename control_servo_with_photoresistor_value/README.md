# Control Servo with Photoresistor Value

This project reads a photoresistor value using an Arduino and uses that input to control a servo motor. The servo position changes based on ambient light level.

## Components

- Arduino board
- Servo motor
- Photoresistor (LDR)
- 10kΩ resistor
- Breadboard and jumper wires

## Usage

1. Upload the Arduino sketch to your board.
2. Open the Serial Monitor to view the photoresistor value.
3. Adjust the light level over the photoresistor and observe the servo movement.
